# Planificación RAL: documento de trabajo y copia versionada

## Programación didáctica (PD)

| Rol | Dónde está |
| --- | --- |
| **Documento de trabajo** | En el almacenamiento privado del profesor, en la carpeta de programaciones didácticas del curso 2026-2027 (Markdown, Word y figuras). |
| **Copia en este repositorio** (Git) | `Planificación/PD_RAL_2026_27.md` y `Planificación/figuras/` |
| Copia de aula | En el almacenamiento privado del profesor, en la carpeta de planificación del módulo RAL del curso 2026-2027. |

Después de editar el documento de trabajo, se **sincroniza** la copia de `Planificación/` de este repositorio (Markdown y figuras) para versionarla. El commit y el push solo se hacen con el visto bueno explícito del profesor, y no implican desplegar GitHub Pages.

Figuras del Word: `figuras/calculo_nota.png` y `figuras/pesos_RA.png`.
