# Imagen: Dominios de Colisión y Difusión

Para añadir una imagen profesional sobre dominios de colisión y difusión, puedes descargarla desde:

## Fuentes recomendadas:

1. **Practical Networking**
   - URL: https://www.practicalnetworking.net/series/packet-traveling/collision-broadcast-domains/
   - Busca el diagrama que muestra hubs, switches y routers

2. **Study CCNA**
   - URL: https://study-ccna.com/collision-broadcast-domain/
   - Imagen educativa clara sobre el concepto

3. **NetworkLessons**
   - URL: https://www.networklessons.com/ccna/collision-domain-and-broadcast-domain
   - Diagramas profesionales de calidad

4. **Cisco Learning Network**
   - Busca "collision domain broadcast domain diagram"
   - Imágenes oficiales de Cisco

## Nombre del archivo:
Guarda la imagen como: `dominio_colision_difusion.png` en esta carpeta.

## Descripción de la imagen:
La imagen debe mostrar:
- Hub conectando varios dispositivos (un dominio de colisión y difusión)
- Switch conectando varios dispositivos (múltiples dominios de colisión, un dominio de difusión)
- Router separando dominios de difusión
- Etiquetas claras indicando cada dominio
