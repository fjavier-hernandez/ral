# Redes de Área Local (RAL)

Apuntes del módulo **Redes de Área Local**, de 1.º del ciclo formativo de grado medio de Sistemas Microinformáticos y Redes (SMR). Curso 2026-2027.

**Web de los apuntes:** <https://fjavier-hernandez.github.io/ral/>

## Contenido

- **Temas:** introducción y arquitectura de redes, medios y capa física, cableado estructurado, capa de enlace, capa de red, enrutamiento, subnetting y VLAN, capa de transporte, NAT e IPv6, y servicios, diagnóstico y protección.
- **Taller:** normas de seguridad y guías paso a paso de las prácticas de taller.
- **Certificación:** orientación hacia la certificación Cisco CCST Networking.

Las entregas, los plazos y las calificaciones se gestionan en el aula virtual del centro (Aules).

## Compilar en local

El sitio está hecho con [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

```bash
pip install "mkdocs-material[imaging]" mkdocs-print-site-plugin
mkdocs serve
```

Después, abre <http://127.0.0.1:8000> en el navegador.
